
# 🌍 Travel Website

A simple web development project created as part of my Web Designing assignment.  
This website provides travel information, destination highlights, and a user-friendly layout to explore places around the world.

## 📌 Project Details

- *Project Name:* Travel Website  
- *Technologies Used:*

## ✨ Features
- 🏝 Attractive homepage with banner images  
- 📖 About Us section describing the website purpose  
- 📍 Table of popular destinations styled with modern HTML.  
- 🔗 External links to famous travel websites
